# Travel Lab — הפעלה ב־Streamlit

ממשק פייתון בעברית: בוחרים תרחיש, עורכים את הבקשה ומריצים את אותן שלוש מערכות — קוד, סוכן יחיד ושלושה סוכנים. התוצאות כוללות חבילה, מסלול, פשרות, בדיקות, מדדים ויומן כלים. אפשר גם לעיין בטיסות, בדירות, ברכבים ובמקומות.

## הדרך הקצרה: Colab מתוך GitHub (מומלץ לקבלת הקוד העדכני)

1. פתחו את [המחברת הראשית ב־Colab](https://colab.research.google.com/github/Noven2155/Travel_Agent/blob/main/notebooks/travel_streamlit_colab.ipynb) והשאירו `SOURCE_MODE="github"`.
2. בחרי **Runtime → Run all** ואשרי את חיבור הדרייב. אין צורך ב־GPU. ההתקנה הראשונה עשויה להימשך כמה דקות.
3. בתא האחרון יופיע ממשק Streamlit. בסרגל הצד הזיני את מפתח Gemini, בחרי תרחיש ולחצי **הרץ השוואה**. אפשר להתחיל בבייסליין ללא מפתח.

המחברת טוענת מ־`travel/project` ומ־`travel/data`, בלי ZIP ובלי להטמיע את הדאטא במחברת. אם תיקיית travel אינה ב־My Drive, עדכני את הנתיב בתא הראשון. מפתח שכבר הוגדר ב־Colab Secrets בשם `GEMINI_API_KEY` נטען אוטומטית, אם נתת למחברת גישה אליו.

הממשק מוצג במסגרת בתוך Colab באמצעות הפונקציה הנתמכת `serve_kernel_port_as_iframe`. השאירי את סביבת Colab מחוברת. אין כאן קישור ציבורי קבוע. אם המסגרת נחסמת בדפדפן, עברי להפעלה במחשב או לאירוח Streamlit Community Cloud; הקוד הוכן גם לשתי הדרכים האלה.

## פתיחה במחשב בחלון דפדפן מלא

הורידי את תיקיית `travel` כך ששתי התיקיות `project` ו־`data` יהיו זו לצד זו. התקיני Python 3.12.

ב־Windows: פתחי את `project/START_STREAMLIT.bat`. בהפעלה הראשונה הוא מתקין את הספריות, ואז פותח את הממשק בדפדפן. השאירי את חלון ההפעלה פתוח. הכתובת המקומית היא `http://localhost:8501`.

ב־Mac/Linux, מתוך project:

```sh
sh start_streamlit.sh
```

או, בסביבת פייתון שכבר הוכנה:

```sh
python -m pip install -r requirements-streamlit.txt
python -m streamlit run streamlit_app.py
```

## קישור קבוע לצוות

לשם כך צריך לפרוס את הקוד דרך חשבון Streamlit Community Cloud עם גישה למאגר GitHub. ההכנה לפריסה נמצאת ב־`streamlit/app.py` וב־`streamlit/requirements.txt`.

במאגר יש לשמור את קוד project בשורש ואת תיקיית data תחת אותו שורש. ב־Create app בוחרים את המאגר והענף, מזינים `streamlit/app.py` כקובץ הראשי ובוחרים Python 3.12 בהגדרות המתקדמות. אין צורך לשמור מפתח במאגר; אפשר להזין אותו בממשק. אחרי הפריסה מתקבל קישור `streamlit.app`.

הממשק הזה טרם פורסם בחשבון Streamlit; העלאת הקבצים לדרייב אינה מפעילה שרת.

## מה רץ ומה נמדד

- ללא מפתח: A רצה בפועל; B ו־C מסומנות כטרם הופעלו.
- עם מפתח ומכסה תקינים: כפתור ההשוואה מפעיל את A/B/C בתהליכים נפרדים דרך המנוע הקיים. כל מערכת מקבלת את אותו קטלוג ואותן בדיקות. מצב הטקסט החופשי הוא ניסוי נפרד ואפשר להפעילו בהגדרות.
- ברירת המחדל היא הרצה במקביל להצגה. למדידת זמנים בחרי הרצה בנפרד.
- מוצגים מחירים, זמן, קריאות כלים ומודל, טוקנים, התאמה להעדפות ותקינות התוכנית. עלות מודל מוצגת רק אם הוזנו תעריפים מאומתים; אין אחוזי הצלחה מומצאים.
- אפשר להוריד JSON של ההרצה ו־CSV מצטבר של המדדים. ב־Colab הקבצים יורדים למחשב; שמרי אותם לפני ניתוק הסביבה. היסטוריית הממשק זמנית.
- קבצי המקור נשארים לקריאה בלבד. לכל חיבור משתמש נוצר אזור עבודה נפרד, ויש כפתור עצירה.

הקטלוג כולל טיסות היסטוריות ומחירי לינה ורכב ממקורות שונים. זמינות ותאריכים מסוימים מדומים או מותאמים. אין כאן הזמנה אמיתית, תשלום או מחיר חי. מחיר החבילה אינו כולל רכיבים חסרים כגון ארוחות, ביקורים ועמלות.
